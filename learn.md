# 📝 Learn Markdown

Welcome to your **Markdown guide**!  
Markdown is a lightweight markup language used to format text on GitHub, websites, and other platforms. This guide will help you learn everything you need to create clean, professional documents.

---

## 1️⃣ Headings

Use `#` symbols to create headings. More `#` → smaller heading.

```md
# H1 - Main Title
## H2 - Section Title
### H3 - Subsection
#### H4
##### H5
###### H6
```

**Example:**

# H1 - Main Title
## H2 - Section Title
### H3 - Subsection

---

## 2️⃣ Text Formatting

| Format | Syntax | Example |
|--------|--------|---------|
| Bold | `**text**` | **Bold text** |
| Italic | `*text*` | *Italic text* |
| Bold + Italic | `***text***` | ***Bold & Italic*** |
| Strikethrough | `~~text~~` | ~~Strikethrough~~ |
| Blockquote | `> text` | > This is a quote |

---

## 3️⃣ Lists

### Unordered List
```md
- Item 1
- Item 2
  - Subitem 2.1
  - Subitem 2.2
```

### Ordered List
```md
1. First
2. Second
3. Third
```

**Example:**

- Apple
- Banana
  - Ripe
  - Green

1. First
2. Second
3. Third

---

## 4️⃣ Links

```md
[Link Text](https://example.com)
```

**Example:**  
[Visit Dev.to](https://dev.to)

---

## 5️⃣ Images

```md
![Alt Text](https://example.com/image.png)
```

**Example:**  
![Markdown Logo](https://markdown-here.com/img/icon256.png)

---

## 6️⃣ Code

### Inline Code
Use backticks `` ` `` for inline code:

```md
`console.log("Hello World")`
```

**Example:** `console.log("Hello World")`

### Code Blocks
Use triple backticks and optional language for syntax highlighting:

````md
```python
print("Hello World")
```
````

**Supported Languages:** `python`, `javascript`, `html`, `css`, `c`, `cpp`, `java`, etc.

---

## 7️⃣ Tables

```md
| Header 1 | Header 2 |
|----------|----------|
| Row 1    | Value 1  |
| Row 2    | Value 2  |
```

**Example:**

| Name  | Age |
|-------|-----|
| Alice | 25  |
| Bob   | 30  |

---

## 8️⃣ Horizontal Rule

Use `---`, `***`, or `___`:

```md
---
```

---

## 9️⃣ Blockquotes & Nested Lists

```md

> - With list item 1
> - With list item 2
```

**Example:**

> This is a quote
> - List item 1
> - List item 2

## 1️⃣3️⃣ HTML in Markdown

Markdown supports inline HTML:

```html
<center>
  <h2>Centered Title</h2>
</center>
```

---

## 1️⃣4️⃣ Links to Sections

You can link to headings inside your README:

```md
[Go to Table of Contents](#table-of-contents)
```

---

## 1️⃣5️⃣ GitHub Markdown Tricks

- **Mention users:** `@username`
- **Mention issues:** `#issue_number`
- **Embed GIFs/images:** `![Alt](url)`
- **Highlight diffs:**

```diff
+ Added line
- Removed line
```

## 1️⃣6️⃣ Example README Structure

```md

- Frameworks: Flask, React

- Feature 2

```bash

npm install
```

```bash
npm start
```

MIT License
```

2. Use code blocks for snippets  
3. Always preview on GitHub  
4. Combine Shields & Skill icons for branding  
5. Use emojis wisely — enhance readability
